Rode cds e dvds na marra com AnyReader 3.0.4  

Postado por MAURICIO FERRAZ Recomende esse blog! Compartilhe!






Tradução automática:
Cópias efetivamente dados corrompidos de qualquer tipo de discos ou ligações erradas se padrão copiando métodos falharem. AnyReader suporta downloads retomada a partir do PC remoto se a ligação foi interrompida durante o processo de cópia (especialmente útil para redes Wi-Fi falíveis).

AnyReader é grande para copiar arquivos de arranhou CD / DVDs defeituosos ou disquete / discos rígidos. Normalmente quando o computador é incapaz de copiar arquivos de um disco danificado ele irá abortar e riscar a parte do arquivo que tenha copiado. AnyReader continuará copiando o arquivo certo para o final, quaisquer dados que não foram recuperados depois de várias tentativas é substituído com espaços em branco. Isso permitirá que você efetivamente ler cada byte de informação que pode ser lido em todos.

Características:

* Lê arquivos de discos com danos físicos.
* Permite-lhe copiar ficheiros de discos com problemas como os setores defeituosos, arranhões ou que apenas dar erros na leitura dos dados.
* Lê os dados, tanto quanto possível.
* Lê os dados de conexões de rede errada. Suporta downloads retomada a partir do PC remoto se conexão foi quebrada durante o processo de cópia.
* Apoio arquivo tamanhos até o sistema de ficheiros limites.
* Fácil de usar-se, intuitive wizard-driven interface.
* Suporta todas as versões do Windows, incluindo o Windows ® 95/98/Me e Windows ® NT/2000/XP/2003.
* E muitos mais!
